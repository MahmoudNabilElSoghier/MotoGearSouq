# نقطة التعادل — الإطار الكامل

## المفاهيم الأساسية

### التكاليف المباشرة

بتتغير مع حجم المبيعات.

| البند | طريقة الحساب |
|---|---|
| تكلفة البضاعة المباعة | متوسط لكل فئة |
| الشحن من تايوان | لكل كونتينر ÷ عدد الوحدات |
| الجمارك + التخليص | % من قيمة البضاعة |
| التغليف | لكل أوردر |
| عمولة بوابة الدفع | 2.5-3% من قيمة البيع |
| الشحن للعميل | لكل أوردر |
| عمولة البائع | % من البيع |

### التكاليف غير المباشرة (الثابتة)

ثابتة شهرياً — مش بتتأثر بالمبيعات.

| البند | النوع |
|---|---|
| إيجار الفروع + المخزن | ثابت |
| رواتب إدارية | ثابت |
| كهرباء + مياه + إنترنت | شبه ثابت |
| تسويق | ميزانية شهرية |
| برامج + استضافة | ثابت |
| إهلاك أصول | ثابت |
| فوائد قروض | ثابت |

## المعادلة

### هامش المساهمة

```text
هامش المساهمة = (الإيرادات - التكاليف المباشرة) / الإيرادات
```

**المعنى**: كل جنيه بتبيعه — كم بيتبقى بعد ما تدفع التكاليف المباشرة؟

### إيراد نقطة التعادل

```text
إيراد نقطة التعادل = التكاليف الثابتة / هامش المساهمة
```

**المعنى**: أقل مبيعات لازم تحققها عشان تغطي كل مصاريفك.

### وحدات نقطة التعادل

```text
وحدات نقطة التعادل = التكاليف الثابتة / (متوسط سعر البيع - متوسط التكلفة المباشرة للوحدة)
```

**المعنى**: عدد الوحدات اللي لازم تبيعها.

### هامش الأمان

```text
هامش الأمان = (الإيرادات الحالية - إيراد نقطة التعادل) / الإيرادات الحالية
```

**المعنى**: كم % من مبيعاتك الحالية هي "أمان" قبل ما تدخل الخسارة؟

---

## مثال عملي

**الافتراضات**:

- مبيعات شهرية: **2,000,000 ج.م**
- تكاليف مباشرة: **1,400,000 ج.م** (70%)
- تكاليف ثابتة: **400,000 ج.م**

**الحساب**:

```text
هامش المساهمة = (2,000,000 - 1,400,000) / 2,000,000
                = 600,000 / 2,000,000
                = 30%

إيراد نقطة التعادل = 400,000 / 0.30
                    = 1,333,333 ج.م

هامش الأمان = (2,000,000 - 1,333,333) / 2,000,000
              = 666,667 / 2,000,000
              = 33.3%
```

**التفسير**:

- لو المبيعات نزلت 33% → الشركة لسه بتغطي مصاريفها
- أقل من كده → خسارة
- **هامش الأمان**: 666,667 ج.م/شهر

## سيناريوهات

### السيناريو 1 — الشهر الحالي

| البند | القيمة |
|---|---|
| مبيعات | 2,000,000 ج.م |
| تكاليف مباشرة | 1,400,000 ج.م |
| هامش المساهمة | 600,000 ج.م |
| تكاليف ثابتة | 400,000 ج.م |
| **صافي الربح** | **200,000 ج.م** |

### السيناريو 2 — لو المبيعات نزلت 20%

| البند | القيمة |
|---|---|
| مبيعات | 1,600,000 ج.م |
| تكاليف مباشرة | 1,120,000 ج.م |
| هامش المساهمة | 480,000 ج.م |
| تكاليف ثابتة | 400,000 ج.م |
| **صافي الربح** | **80,000 ج.م** |

### السيناريو 3 — لو المبيعات نزلت 40%

| البند | القيمة |
|---|---|
| مبيعات | 1,200,000 ج.م |
| تكاليف مباشرة | 840,000 ج.م |
| هامش المساهمة | 360,000 ج.م |
| تكاليف ثابتة | 400,000 ج.م |
| **صافي الربح** | **-40,000 ج.م (خسارة)** |

**الخلاصة**: أي مبيعات أقل من 1,333,333 ج.م = خسارة.

## قيمة النظام

### 1. تسجيل تلقائي لتكلفة البضاعة المباعة

النظام بيسجل تكلفة كل منتج تلقائياً — مش تقدير.

### 2. لوحة نقطة التعادل في الوقت الفعلي

الحج تامر يشوف نقطة التعادل في أي لحظة من الموبايل.

### 3. تنبيهات استباقية

> "بيعت بـ 1,200,000 ج.م الشهر ده — قربت من نقطة التعادل."

### 4. تحليل "لو"

> "محتاج تبيع 200 قطعة أكتر لتحقيق ربح 300,000 ج.م."

## أسئلة لازم تاخد إجاباتها من الحج تامر

1. **مبيعات شهرية** — رقم دقيق أو تقريبي؟
2. **التكاليف المباشرة** — % من المبيعات؟
3. **التكاليف الثابتة** — قائمة كاملة؟
4. **موسمية** — في شهور أعلى/أقل؟

**بعدها** — تقدر تحسب نقطة التعادل قدامه في المقابلة.
